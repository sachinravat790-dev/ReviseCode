Spaced Repetition Configuration

Mandatory Spaced Milestones

ReviseCode automatically enforces 5 non-negotiable milestones for every question: Day 3, Day 7, Day 12, Day 20, and Day 30. These intervals are mathematically calibrated according to the Ebbinghaus forgetting curve.

Google Gemini API Integration

How to configure Gemini API:

ReviseCode uses Google Gemini (gemini-2.5-flash) for arbitrary coding, algorithmic, system design, and mathematics reasoning in Hindi, English, and Hinglish.

  1. Get a free Gemini API key from Google AI Studio.
  2. Enter the API key below and click Test & Save Key.
  3. Alternatively, add GEMINI_API_KEY=your_key in your backend/.env file.
Stored strictly in backend environment variables. Never returned to frontend network requests.

Data Management & Persistence

Storage Architecture Notice

The ReviseCode backend API currently operates in In-Memory Storage Mode. All questions, revisions, subjects, and session logs are held in memory by the Express backend service.

Note: In-memory data will reset to default seeds whenever the backend server restarts. Use the Export Data feature below to download JSON snapshots. Permanent database persistence (e.g., PostgreSQL, MongoDB, or Cloud Firestore) can be configured in production.
